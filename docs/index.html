What the benchmark asks

Change what matters.
Hold the rest still.

Three complementary checks separate following the task from reacting to the explanation.

01 / FOLLOW THE GOAL
G₁ → A
G₂ → B

Does the choice change
when it should?

Keep the page, actions, and explanations fixed. Change the goal so that the correct action must change. A page counts as correct only if both goals are answered correctly.

02 / RESIST WORDING CHANGES
v₁ ⇄ v₂
A → A

Does the choice stay
when it should?

Keep the page, goal, and actions fixed. Switch between checked explanation versions for the same actions. Measure how often the choice flips.

03 / MEASURE THE BENEFIT

Do explanations
actually help?

Compare each model with and without explanations. Their net effect is the change in two-goal accuracy, not the accuracy difference between two models.

The research question

Same explanations.
Different effects.

How a model’s training explanations are generated can change how it responds to the same explanations later.

Our experiments compare original-data training with PreAct, which reconstructs candidate explanations using the same information available before an action is executed. WebContrast holds the test explanations fixed.
