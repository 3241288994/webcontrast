02 / DATA ACCESS

Annotations and source pages are separate.

WebContrast adds paired goals, candidate actions, labels, and checked explanation versions to pages derived from Mind2Web. The planned public package contains these annotations and source identifiers, not a redistributed copy of the complete upstream test HTML or screenshots.

  1. Obtain Mind2Web through its official access instructions.
  2. Download the matching WebContrast annotation release when available.
  3. Run the version-specific reconstruction tool and verify the resulting observation hashes before evaluation.

Exact reconstruction is being prepared and validated. Source IDs alone do not reproduce the benchmark’s frozen, simplified page observations. Do not substitute the full raw HTML and treat it as the same evaluation input.

03 / LOCAL INSPECTION

Read your data in your browser.

The explorer can read a locally reconstructed JSONL, JSON, or gzipped JSONL file. It requires no account and sends no file contents to a server. Source HTML is displayed as escaped text; scripts, forms, and remote resources are not executed.

Each record must contain id, website, observation, two goals, two actions, opposite correct_action_indices, and two notes with texts.phrasing1 and texts.phrasing2. Files are limited to 50 MB after decompression for browser responsiveness.

In version 1, action A uses its first explanation and B uses its second. In version 2, A uses its second and B uses its first. An explanation always stays attached to the action it describes.

Public examples on this site are original fictional illustrations. They are not benchmark records, and their revealed answers are not model predictions.

04 / WHAT THE NUMBERS MEAN

Three measurements, three questions.

Two-goal accuracy
A page receives credit only when the model chooses correctly for both opposing goals. With explanations, score both goals within each version and then average the versions. This is not the average of two separate goal accuracies.
Explanation effect
For the same model: accuracy with explanations minus accuracy without explanations. Positive values mean a net benefit; negative values mean a net loss. Compare this within-model difference across training conditions to study how training changes explanation use.
Explanation-version flip rate
How often a model changes its action choice when only explanation versions change. We report the rate among resolved comparisons, with coverage in the downloadable result data. Lower is more stable, but stability alone does not prove an explanation is useful.

Both candidate orders are evaluated to reduce position effects. Aggregation follows the stated model interface; it is not universally a single greedy prediction. Invalid or unresolved goal choices do not count as correct. Training seeds and input variants do not increase the number of independent pages.

05 / REPRODUCIBILITY

Version the data and the evaluator together.

The public research-code release is being prepared. It will identify the data version, model checkpoint, prompt and scoring interface, and required upstream resources. The existing research results are shown on the results page; this website is not an online evaluation server.

For reproducible comparisons, retain the exact page set and explanation text, report with- and without-explanation accuracy, and compare released models with their bases using matched interfaces where possible.

06 / PROVENANCE

Build on the source. Keep the distinction clear.

Source pages come from Mind2Web. Its dataset is declared under CC BY 4.0; its maintainers also request that unzipped test data not be redistributed online to reduce contamination. These are separate considerations. Our release separates the added annotations from the upstream page material and retains provenance.

The 500 pages were checked during development. The benchmark is not a record of 500 newly executed browser tasks, and its review process should not be described as an independent human annotation study. The harder extension uses checked wording variants, not a claim that every pair was independently written by two generators.

See the upstream licensing information and CC BY 4.0. Any eventual WebContrast annotation license will be stated separately. This site does not imply upstream endorsement.
